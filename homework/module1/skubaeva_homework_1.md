# Домашнє завдання №1
## Основи комп'ютерних мереж

### Завдання 1. Дослідження мережі

**Команда:** `ip a`

**Результат виконання:**

```text
2: enp0s8: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    link/ether 08:00:27:4b:cd:67 brd ff:ff:ff:ff:ff:ff
    inet 10.0.2.15/24 brd 10.0.2.255 scope global dynamic noprefixroute enp0s8
```

**Визначені параметри:**

- Інтерфейс: `enp0s8`
- Тип підключення: Ethernet (віртуальний мережевий адаптер)
- MAC-адреса: `08:00:27:4b:cd:67` — канальний рівень OSI (2)
- IP-адреса: `10.0.2.15` — мережевий рівень OSI (3)
- Маска: `255.255.255.0` (`/24`) — використовується на мережевому рівні OSI (3)
- Gateway: `10.0.2.2`
- Broadcast: `10.0.2.255`
- Hosts: 254 доступні адреси

**Пояснення:**

Мережева адреса `10.0.2.15` належить до приватного діапазону IPv4. Маска `/24` означає, що 24 біти визначають мережу, а 8 бітів — вузли. У підмережі `10.0.2.0/24` доступні 254 адреси для пристроїв. Широкомовна адреса `10.0.2.255` використовується для надсилання пакетів усім вузлам підмережі. Шлюз `10.0.2.2` забезпечує передавання пакетів до інших мереж.

### Завдання 2. Дослідження маршрутизації

**Команда:** `ip r`

**Результат виконання:**

```text
default via 10.0.2.2 dev enp0s8 proto dhcp src 10.0.2.15 metric 100
10.0.2.0/24 dev enp0s8 proto kernel scope link src 10.0.2.15 metric 100
```

**Визначені параметри:**

- Основний шлюз: `10.0.2.2`
- Мережевий інтерфейс: `enp0s8`
- Протокол отримання маршруту: DHCP
- Локальна мережа: `10.0.2.0/24`
- Другий маршрут: створений ядром Linux (`proto kernel`)

**Пояснення:**

Команда `ip r` показує таблицю маршрутизації. Основний маршрут проходить через шлюз `10.0.2.2`. Позначка `proto dhcp` означає, що маршрут отримано через DHCP. Другий маршрут створено ядром Linux для локальної мережі. Значення `metric 100` визначає пріоритет маршруту.

### Завдання 3. Знаходження публічної IP-адреси

**Команда:** `curl ifconfig.io`

**Результат виконання:**

```text
78.27.177.11
```

**Порівняння IP-адрес:**

- Локальна IP-адреса: `10.0.2.15`
- Публічна IP-адреса: `78.27.177.11`
- Адреси різні.

**Пояснення:**

Локальна IP-адреса використовується всередині приватної мережі віртуальної машини, а публічна — для зв'язку з інтернетом. Адреси відрізняються через технологію NAT (Network Address Translation). У цьому випадку віртуальна машина використовує NAT у VirtualBox, а домашній роутер також може виконувати трансляцію адрес. Це дозволяє пристроям із приватними IP-адресами отримувати доступ до інтернету.

Також було перевірено таблицю маршрутизації та встановлено використання DHCP. Отримані результати допомогли зрозуміти принципи IP-адресації, маршрутизації та роботи NAT.
